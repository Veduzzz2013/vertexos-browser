About Vertex OS

Vertex OS is an independent Linux-based operating system distribution developed by The Vertex Project. It provides a complete desktop environment with native hardware deployment installers, offline-first local productivity tools, and sovereign system management.

The operating system features the Vertex Cloud Sync background subsystem, which enables users to link their Google Drive storage directly to the local Linux filesystem without routing through external relay servers.

Google OAuth 2.0 Integration

Google API & Google Drive Integration Purpose

Vertex OS integrates Google OAuth 2.0 to offer seamless, sovereign cloud storage synchronization for users who choose to link their Google Account.

1. Requested Scopes & Intended Usage

Vertex OS requests access to https://www.googleapis.com/auth/drive (or drive.file), userinfo.email, and userinfo.profile solely to:

  • Mount the user's remote Google Drive cloud storage to a local virtual directory path at ~/Vertex Cloud on their computer.
  • Allow users to view, edit, and back up personal files via local file managers (such as Nautilus, Dolphin, or Thunar).
  • Execute background filesystem synchronization using the embedded rclone VFS engine.
  • Personalize the local desktop profile avatar and recovery email during system setup.

2. Local-Only Token Storage & Zero External Relays

All OAuth 2.0 access and refresh tokens are written directly to the user's local disk at ~/.config/rclone/rclone.conf with POSIX 0600 (owner read/write only) security permissions. Vertex OS transmits zero credentials, zero telemetry, and zero file payloads to any central server operated by The Vertex Project or third parties.

3. Google API User Data Policy Compliance

Privacy Policy

Effective Date: August 20, 2026 • Published by The Vertex Project

1. Data Sovereignty

We do not collect telemetry, track user activity, or aggregate personal information. The operating system operates entirely offline-first.

2. Google Account Credentials

When you link Google Drive, your authentication token is communicated directly between your local client and Google's OAuth endpoints. Tokens are stored locally on your physical drive and are never sent to external servers.

3. Token Revocation & Data Deletion

You can revoke Vertex OS access at any time by removing your local configuration file (~/.config/rclone/rclone.conf) or via your Google Account Security Dashboard.
